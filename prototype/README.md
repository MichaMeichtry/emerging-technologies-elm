# IT Service Desk - Elm Prototype

An IT support ticket management system built in Elm.
Part of the 63-51 Emerging Technologies project - Elm Programming Language.

## For Users

Open `public/index.html` directly in your browser. No installation needed.

## For Developers

When you make changes to any Elm file, recompile with:

```bash
elm make src/Main.elm --output=public/app.js
```

Then refresh the browser to see the changes.

### Requirements

- Elm 0.19.1 - https://guide.elm-lang.org/install/elm.html
